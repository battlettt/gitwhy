# GitWhy

Point at any line of code and get the story behind it: who wrote it, why it exists, what changed around it, and whether it is still alive.

GitWhy walks git history with blame, log, and diffs to answer "why does this code exist" — the commit that introduced a line, the message and author behind it, the files that changed alongside it, how often it has been touched since, and whether it looks stale or hot. Terminal summary plus an HTML report.

Local CLI, Python standard library only, works on any git repo.
